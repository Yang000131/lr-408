# 树

## 树的性质

- **结点关系**：树中结点数等于所有结点的度数之和加 1
- **度为 $m$ 的树**：
  （各结点的度的最大值为 $m$ => 至少有一个结点度为 $m$ => 一定是非空树，至少有 $m + 1$ 个结点）
  - 度为 $m$ 的树的第 $i$ 层上至多有 $m^{i-1}$ 个结点 $(i \ge 1)$
  - 高度为 $h$、度为 $m$ 的树至少有 $h + m -  1$ 个结点
- **$m$ 叉树**：
  (每个结点最多只能有 $m$ 个子结点 => 允许所有结点的度数 $< m$ => 可以是空树)
  - $m$ 叉树第 $i$ 上至多有 $m^{i-1}$ 个结点 $(i \ge 1)$
  - 高度为 $h$ 的 $m$ 叉树至少有 $h$ 个结点，至多有 $\frac{m^h - 1}{m - 1}$ 个结点
  - 具有 $n$ 个结点的 $m$ 叉树的最小高度为
- **公式推导**：
  - 总结点数 $n = n_0 + n_1 + n_2 + \dots + n_m$。
  - 总分支数 $= 1n_1 + 2n_2 + \dots + mn_m$。
  - 总结点数 $=$ 总分支数 $+ 1$。

## 二叉树的性质

- 基本性质：
  - 非空二叉树的叶子结点数 $n_0$ 等于度为2的结点数 $n_2$ 加1，即 $n_0 = n_2 + 1$。
  - 非空二叉树第 $k$ 层上至多有 $2^{k-1}$ 个结点 $(k \ge 1)$。
  - 高度为 $h$ 的二叉树至多有 $2^h - 1$ 个结点 $(h \ge 1)$。
- 完全二叉树性质：
  - 具有 $n$ 个 $(n>0)$ 结点的完全二叉树高度为 $\lfloor \log_2 n \rfloor + 1$。
  - 若完全二叉树有 $n$ 个结点，则有 $n - \lfloor \frac{n}{2} \rfloor$ 个叶子结点。
  - **结点个数奇偶性**：
    - 若有 $2k$ 个（偶数）结点，则 $n_1 = 1, n_0 = k, n_2 = k - 1$。
    - 若有 $2k-1$ 个（奇数）结点，则 $n_1 = 0, n_0 = k, n_2 = k - 1$。
