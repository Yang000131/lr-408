## BFS、DFS的应用

| 应用场景     | 推荐算法    | 原因                     |
|----------|---------|------------------------|
| 无权图最短路径  | BFS     | 首次访问即最短                |
| 判断连通性    | DFS/BFS | DFS 更省空间               |
| 拓扑排序     | 两者皆可    | Kahn（BFS） vs DFS 后序    |
| 检测环      | DFS     | 递归栈天然支持                |
| 回溯/组合/排列 | DFS     | 天然递归结构                 |
| 强连通分量    | DFS     | Tarjan/Kosaraju 基于 DFS |
| 层级遍历     | BFS     | 队列天然分层                 |
| 状态空间最少步数 | BFS     | 最短路径保证                 |
