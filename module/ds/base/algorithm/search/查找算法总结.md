#### 2.3 拓展

**查找排序数组中第一个等于给定值的元素**

- 标准实现

```cpp
int find_first_target(vector<int> &nums, int target) {
        int left = 0, right = nums.size();
        int ans = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                ans = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return ans;
    }
```

- STL

```cpp
auto it = lower_bound(nums.begin(), nums.end(), target);
if(it != nums.end() && *it == target)            
    return it - nums.begin();   
```
