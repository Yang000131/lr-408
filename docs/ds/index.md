# 数据结构

## 考试大纲 {#exam-outline}

### 考察目标 {#exam-target}

::: tip 考察目标
(1) 掌握数据结构的基本概念、基本原理和基本方法。  
(2) 掌握数据的逻辑结构、存储结构及基本操作的实现，能够对算法进行基本的时间复杂度和空间复杂度的分析。  
(3) 能够运用数据结构的基本原理和方法进行问题的分析与求解，具备采用 C 和 C++ 语言设计与算法实现算法的能力。
:::
